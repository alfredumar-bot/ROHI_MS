ROHI GPS TEST BUILD - BORNO + ADAMAWA
======================================

Office coordinates:
1. Borno State Office: 11.797352, 13.143040 (100 m)
2. Adamawa HQ: 9.2781640, 12.432640 (100 m)

IMPORTANT TEST BEHAVIOUR
- The app NEVER uses the office coordinate as the phone's current location.
- Check-In requires a real phone GPS/location fix.
- The app compares the live phone location with the selected user's State Office.
- If the phone is within 100 m, Check-In is accepted and the live coordinate is saved.
- If outside 100 m, Check-In is denied and the distance is displayed.
- Android/Pydroid testing uses Plyer GPS first and Android LocationManager fallback when available.
- A recent phone location may be used only when it is <=60 seconds old and <=100 m accuracy.
- No live location fix means Check-In is denied.

PYDROID TEST
1. Extract this ZIP in Pydroid.
2. Install/confirm Kivy, KivyMD, Plyer and required project packages.
3. Turn Android Location ON.
4. Give Pydroid/ROHI Attendance Precise Location permission.
5. Login as a staff member whose State Office is Borno State Office.
6. Go to Dashboard and press CHECK IN.
7. At Borno office, the dashboard should show the phone's actual GPS and 'Captured Within Office'.
8. Repeat with an Adamawa HQ staff record at 9.2781640, 12.432640.
9. If it says GPS unavailable, check the Pydroid console/logs for 'Plyer GPS' or 'Android LocationManager' messages.
