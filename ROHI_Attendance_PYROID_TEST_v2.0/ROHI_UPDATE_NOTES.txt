ROHI Attendance App - Updated Build

Key changes:
1. Borno State Office GPS: 11.797352, 13.143040
2. Adamawa HQ GPS: 9.2781640, 12.432640
3. Timesheet hours: Monday-Thursday = 8 hours; Friday = 4 hours.
4. Timesheet Excel export now populates the supplied Corrected Timesheet.xlsx
   template so the supplied logo, borders, column widths, row heights and
   merged cells are preserved.
5. Staff Registration Excel export now uses the supplied Rohi_Staff on IMS.xlsx
   template and exports all local staff records while preserving its layout.
6. Attendance Excel export uses the supplied Rohi_Attendance Report.xlsx template.
7. Signature and staff-photo selection now uses Plyer's stable file chooser,
   reducing Android activity-result logouts/crashes. Images are resized before
   storage/export to improve speed.
8. Android email/share code uses android.os.Build$VERSION correctly, fixing the
   Build.VERSION error.
9. Login session is persisted and restored after Android activity/process
   recreation; it is cleared only by the LOG OUT button.
10. Server Connection now includes Excel Auto-Sync Connections for Attendance,
    Timesheet, Leave and Staff links, with Save/Connect/Open buttons.
11. Dashboard shows Excel Sync connection status.
12. Staff Excel mirror is scheduled every 24 hours and is also generated after
    registration/profile edits.
13. Attendance Excel mirror is scheduled at 5:00 PM each day and catches up on
    the next app launch if the phone was offline at 5 PM.
14. Exported Timesheet/Staff/Attendance workbooks can be sent to configured HTTP
    upload endpoints in the background without blocking the UI.
15. excel_sync_server.py is included as an optional server receiver. It stores
    uploads in separate folders that can be placed inside a Google Drive/
    OneDrive sync directory.

Important:
A Google Drive folder URL is a browse/share link, not a direct upload API.
For actual automatic upload to those folders, run the included server receiver
(or use an authenticated Drive API/Apps Script endpoint) and put its /upload
URL into the corresponding upload endpoint field in the app.
